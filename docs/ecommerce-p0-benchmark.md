# 电商视觉工作台 P0 基准方案

更新日期：2026-08-06

## 目标

把现有的单图 Prompt 生成功能升级为面向小白用户的项目式电商套图工作流。第一批覆盖：

- 淘宝 / 天猫
- 抖音电商
- Amazon
- Shopify

公开商品页只用于研究信息结构、视觉槽位和平台规则。产品内置演示素材必须使用自有、授权或自行生成的无品牌素材，不复制第三方品牌图片、Logo、包装和文案。

## 已选真实参考

### 淘宝 / 天猫

1. HBN 泛醇 B5 面霜商品页
   - https://mo.m.tmall.com/page/3884283?item_id=599217001492
   - 研究点：护肤包装一致性、单品主视觉、成分与功效信息、质地特写、适用人群。
2. 天猫国际美妆频道中的护肤套装
   - https://www.tmall.com/wow/jinkou/act/personalcare
   - 研究点：单品与套装、促销信息、规格组合、货架缩略图。
3. 淘宝图片上传与多图能力
   - https://open.taobao.com/anno?docId=25787&docType=12
   - https://open.taobao.com/doc.htm?docId=122315&docType=1
   - 研究点：原图质量、多角度素材、销售属性多图、1:1 与 3:4 素材。

### 抖音电商

1. 优质商品图创建指南（服饰）
   - https://school.jinritemai.com/doudian/web/article/aJdDJTsTH6E4
   - 研究点：快速识别商品、主体清晰、核心卖点、推荐流量场景。
2. 商品主图发布规范
   - https://school.jinritemai.com/doudian/web/article/aHv3JRVNZb5c
   - 研究点：低质画风、边框、水印、变形、信息准确性。
3. 3:4 主图及素材图创建说明
   - https://school.jinritemai.com/doudian/web/articlev0/aHKu33ExA3nV
   - 研究点：1:1 与 3:4 双规格、移动端展示。
4. 主图打标操作指南
   - https://school.jinritemai.com/doudian/web/articlev0/aHmEpRyXjePS
   - 研究点：商品图层、文字图层、卖点、价格、活动模板和批量合图。

### Amazon

1. Stanley Quencher H2.0 商品详情页
   - https://www.amazon.com/dp/B0FSP3K9B7
   - 研究点：白底主图、角度图、结构卖点、尺寸、使用场景、颜色变体。
2. Amazon Product image guide
   - https://sellercentral.amazon.com/help/hub/reference/external/G1881

   - https://sellercentral.amazon.com/help/hub/reference/external/200216080
   - 研究点：合规主图、辅助图、不同角度、功能和使用环境；官方建议至少六张图片并提供视频。

### Shopify

1. memobottle
   - https://www.memobottle.com/
   - 研究点：极简产品主视觉、尺寸系列、颜色变体、配件、生活方式场景和品牌故事。
2. waterdrop
   - https://www.waterdrop.com/
   - 研究点：食品包装、口味系列、组合装、功效标签、场景图和促销套装。
3. Our Place Shopify 案例
   - https://www.shopify.com/case-studies/our-place
   - 研究点：高颜值生活方式商品、内容化商品页和跨渠道品牌视觉。
4. Shopify Product media
   - https://help.shopify.com/en/manual/products/product-media
   - 研究点：图片、视频、3D 模型、变体媒体和可访问性文字。

## 自有基准商品

### A. 护肤面霜

- 形态：玻璃罐、纸盒、膏体质地
- 验证：包装文字、Logo 位置、颜色、材质、套装一致性
- 重点平台：淘宝 / 天猫

### B. 通勤外套

- 形态：单件服装、模特上身、局部面料
- 验证：版型、颜色、五金、人物一致性、1:1 和 3:4 适配
- 重点平台：抖音电商

### C. 保温随行杯

- 形态：杯身、把手、吸管、杯盖、颜色变体
- 验证：几何结构、尺寸图、不同角度、白底主图、生活方式图
- 重点平台：Amazon

### D. 扁平随身水瓶

- 形态：透明瓶体、彩色保护套、配件和组合装
- 验证：高级品牌视觉、系列陈列、生活方式、视频封面和 3D 需求说明
- 重点平台：Shopify

上述商品使用虚构品牌名称和自行生成的基础产品图，不使用真实案例的商标与包装。

## 平台套图定义

### 淘宝 / 天猫套图

1. 商品首图 1:1
2. 商品首图 3:4
3. 白底商品图
4. 核心卖点图
5. 材质 / 成分 / 细节图
6. 使用场景图
7. 规格或套装图
8. SKU 颜色 / 款式图
9. 活动氛围图（文字独立图层）
10. 详情页模块：痛点、卖点、细节、参数、场景、信任信息

### 抖音电商套图

1. 1:1 商品封面
2. 3:4 商品素材图
3. 三秒卖点视觉
4. 真人 / 使用场景图
5. 细节特写
6. 对比或效果图
7. 活动打标版本（价格、利益点为独立文字图层）
8. 短视频封面和 6 镜头脚本

### Amazon 套图

1. 合规白底主图
2. 正面 / 背面 / 侧面角度图
3. 核心功能图
4. 尺寸和比例图
5. 使用场景图
6. 材质和细节图
7. 包装清单图
8. 颜色 / 规格变体图
9. 视频封面和镜头脚本

### Shopify 套图

1. 商品页 Hero
2. 集合页缩略图
3. 产品画廊多角度图
4. 生活方式图
5. 材质细节图
6. 使用步骤图
7. 组合装 / 交叉销售图
8. 颜色与 SKU 变体图
9. 社交分享图
10. 视频封面和 3D 模型制作说明

## P0 产品流程

1. 新建商品项目
2. 选择平台和商品行业
3. 上传或创建商品基础素材
4. 填写商品名称、卖点、规格、受众和禁用内容
5. 选择视觉方向
6. 生成一张“商品母版图”并确认
7. 基于母版生成整套图片
8. 单张重做、局部修改和版本对比
9. 编辑文字、Logo、价格和参数图层
10. 平台规则检查
11. 按平台命名并打包下载 ZIP

## 验收标准

- 小白用户不需要手写 Prompt 即可完成套图。
- 同一商品在整套图中颜色、包装、结构和配件数量一致。
- 价格、卖点、参数和 Logo 必须为可编辑图层。
- 每张图明确标注用途和平台槽位。
- 单张失败不会导致整个任务重做。
- 可对单张图重新生成、回退版本和锁定商品主体。
- 导出前检查比例、像素、文件格式、文字安全区和平台规则版本。
- 生成结果按项目、平台、套图和版本保存。

## 实施顺序
