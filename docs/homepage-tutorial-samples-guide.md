# Pic365 主页教学 Sample 任务指导书

版本：V1.0
制定日期：2026-09-06
当前状态：10 套本地评审版已建立并接入本地主页；公开授权、Sample 06 换鞋分支重做和正式发布尚未完成

## 1. 任务目标

使用 Pic365 的真实功能和主账号资产库中的优质图片，制作 10 套可独立更换的场景化教学 Sample，并放入主页“真实场景课堂”橱窗。

教学内容必须让第一次访问 Pic365 的客户快速明白：

1. 自己遇到的实际问题是什么。
2. 应该进入 Pic365 的哪个功能。
3. 需要准备哪些图片。
4. 按什么顺序操作。
5. 最终可以获得哪些可直接使用的结果。

本项目不是普通的功能介绍，也不是只展示漂亮成品。每套 Sample 都必须完整呈现“原始素材 → 操作步骤 → 生成结果 → 下一步使用”。

## 3. 素材使用原则

### 3.1 可以使用

- Pic365 主账号自己上传或生成的素材。
- 主账号电商项目中已经成功生成的主图、场景图、细节图和视频封面。
- 经人工确认内容、构图、商品结构和文字均正确的作品。
- 已确认可以公开展示的人物、商品和品牌素材。

### 3.2 不可直接使用

- 其他普通用户的私人资产。
- 含手机号、邮箱、微信号、二维码、API Key 等隐私信息的图片。
- 未确认公开授权的人脸、商标、包装或版权角色。
- 商品结构错误、文字乱码、手指异常、穿帮、低清晰度或风格与标题不符的图片。
- 只有漂亮效果、但无法对应 Pic365 实际操作过程的图片。

### 3.3 上线前处理

- 教学图片必须从资产库正式导出，不得在公开主页直接引用私人资产 API 地址。
- 删除图片 EXIF 等非必要元数据。
- 统一生成 WebP 展示版本，同时保留内部原始文件。
- 涉及品牌 Logo、人物肖像和版权角色时，必须单独标记授权状态。
- 页面展示的提示词必须删除个人信息、内部系统提示词和渠道信息。

## 4. 统一文件夹规范

计划根目录：

```text
content/homepage-tutorials/
```

每个场景独立存放：

```text
content/homepage-tutorials/
  01-backpack-store-set/
    tutorial.json
    README.md
    cover.webp
    source/
      source-01.webp
      source-02.webp
    steps/
      step-01.webp
      step-02.webp
      step-03.webp
    results/
      result-01.webp
      result-02.webp
      result-03.webp
    compare/
      before-after.webp
    video/
      preview.mp4
    provenance.json
```

文件职责：

- `tutorial.json`：主页和详情页需要的公开标题、摘要、步骤、入口、排序及上下架状态。
- `README.md`：该案例的制作说明和人工验收记录。
- `cover.webp`：主页橱窗封面，建议比例 4:3。
- `source/`：教程允许公开展示的输入素材。
- `steps/`：Pic365 真实界面的操作截图。
- `results/`：最终采用的结果图。
- `compare/`：前后对比或多版本比较图。
- `video/`：可选，存放短预览视频。
- `provenance.json`：内部素材来源、资产 ID、授权状态及生成记录，不输出到公共页面。

首页不应把 10 个案例写死在组件中。以后应通过统一索引读取：

```text
content/homepage-tutorials/index.json
```

索引至少支持：`enabled`、`featured`、`order`、`category`、`cover` 和 `slug`，以便以后直接更换橱窗内容。

## 5. 单套教程的统一内容结构

每套教程必须包含：

1. **真实问题**：客户为什么需要做这件事。
2. **适用用户**：电商运营、设计师、广告团队、短视频团队或教育用户。
3. **准备素材**：需要几张图，每张图承担什么角色。
4. **使用入口**：单图创作、批量改图、电商套图、无限画布、资产库或视频创作。
5. **操作步骤**：建议 3～6 步，每一步对应真实界面截图。
6. **可复制提示词**：只包含用户需要输入的内容。
7. **最终结果**：至少 3 张有效结果，或一组前后对比。
8. **经验提示**：告诉用户容易出错的地方。
9. **下一步操作**：继续精修、加入画布、生成视频、下载或进入资产库。
10. **直接体验按钮**：跳转到正确功能，并尽可能预填案例配置。

## 6. 十个教学场景

### Sample 01：一张背包图，生成完整商城套图

目录：`01-backpack-store-set`

- 目标用户：跨境电商、独立站运营、商品设计师。
- 真实任务：只有一组普通背包照片，需要快速制作主图、场景图、角度图、材质图和社媒图。
- 使用能力：电商套图、商品母版、平台规格、视觉方向、批量生成、专业交付。
- 推荐素材：主账号资产库中的黑色双肩包主图、模特背包场景和包体细节图。
- 教学步骤：建立项目 → 选择 Shopify → 上传商品素材 → 确认母版 → 选择视觉方向和图单 → 整套生成并交付。
- 必须展示：商品结构在多张结果中保持一致；横图、方图、竖图用途不同。
- 首页标题：**一张背包图，生成完整商城套图**
- 首页短句：上传真实商品，主图、场景图和细节图一次完成。
- 验收结果：至少 1 张主图、1 张人物场景图、1 张材质特写、1 张社媒图。

### Sample 02：一串手链，完成抖音广告素材

目录：`02-bracelet-douyin-campaign`

- 目标用户：饰品商家、直播电商、短视频运营。
- 真实任务：把普通手串素材变成佩戴效果、材质特写、三秒卖点图和视频封面。
- 使用能力：电商套图、商品母版、人物场景、竖屏构图、图生视频入口。
- 推荐素材：男士五行中药手串主图、佩戴场景图、材质特写和现有视频封面。
- 教学步骤：录入商品事实 → 确认手串数量和材质 → 选择抖音 → 生成竖版图组 → 采用结果 → 让图片动起来。
- 必须展示：珠子数量、颜色、排列和佩戴位置不能漂移。
- 首页标题：**一串手链，变成抖音广告素材**
- 首页短句：商品不变，自动生成佩戴、卖点和视频封面。
- 验收结果：至少 4 张统一商品身份的竖版素材。

### Sample 03：一张商品图，生成五种广告方向

目录：`03-one-product-five-campaigns`

- 目标用户：广告设计师、品牌运营、社交媒体团队。
- 真实任务：用同一件商品快速测试五种视觉方向。
- 使用能力：单图创作、母版、风格词库、一图多提示词、任务列表和版本比较。
- 推荐方向：极简棚拍、自然户外、轻奢质感、节日氛围、社交媒体广告。
- 教学步骤：上传母版 → 粘贴五行提示词 → 选择适当尺寸 → 提交任务 → 比较结果 → 采用一个方向继续精修。
- 必须展示：同一商品不被重新设计；五个方向具有明确差异。
- 首页标题：**一张商品图，测试五种广告创意**
- 首页短句：不用反复填表，一次比较五种可用方向。
- 验收结果：5 张风格清晰且商品一致的广告图。

### Sample 04：批量统一一组商品照片

目录：`04-batch-product-unification`

- 目标用户：网店运营、摄影后期、商品录入团队。
- 真实任务：多张角度不同、背景不同的商品照片，需要统一背景、光线、比例和画面风格。
- 使用能力：批量改图、多图共用提示词、图片与提示词一对一、排序调整、保留原图尺寸。
- 推荐素材：背包的正面、侧面、上身和细节照片。
- 教学步骤：一次上传多张图 → 选择“多图共用一个提示词” → 输入统一要求 → 调整顺序 → 批量提交 → 检查异常单张并重做。
- 必须展示：多张结果的背景和光线统一，商品角度仍对应原图。
- 首页标题：**十张商品照片，一次统一风格**
- 首页短句：批量换背景、统一光线，异常图片单独重做。
- 验收结果：至少 4 张统一风格的商品图和一张拼版对比图。

### Sample 05：精准删除玩偶照片中的杂物

目录：`05-toy-precision-retouch`

- 目标用户：商品摄影、二手电商、内容设计师。
- 真实任务：商品图中存在飞虫、杂物、错误文字或小面积瑕疵，只想修改局部。
- 使用能力：母版、涂抹标注、AI 精修、子版本和原图下载。
- 推荐素材：主账号资产库中的猪八戒玩偶商品图。
- 教学步骤：上传母版 → 涂抹需要删除的位置 → 输入“仅删除涂抹区” → 生成子版本 → 放大检查边缘 → 采用结果。
- 必须展示：未涂抹区域没有变化；玩偶造型、颜色和背景保持一致。
- 首页标题：**只改一个地方，其余画面完全保留**
- 首页短句：圈出杂物，精准删除，不必重新生成整张图。
- 验收结果：原图、标注图、结果图三联对比。

### Sample 06：给同一位模特换包、手表、鞋子和发型

目录：`06-model-accessory-swap`

- 优先级：核心案例，主页首屏推荐。
- 目标用户：服饰电商、箱包、鞋类、手表和美妆发型商家。
- 真实任务：保留同一位模特、姿势、服装和背景，分别替换不同商品或发型，减少重复拍摄。
- 使用能力：单图创作、母版、多参考图、子版本、无限画布对比、局部精修。
- 准备素材：1 张授权成年模特全身或半身图，1 张包商品图，1 张手表商品图，1 张鞋商品图，可选 1 张发型参考图。
- 正确制作方式：从同一个母版分别创建四个独立子版本，不能用一条提示词同时更换四项。
- 四个分支：
  1. 换包：锁定人物、衣服、姿势和背景，只替换包。
  2. 换手表：保持手腕姿势，保证表盘方向、尺寸和佩戴关系真实。
  3. 换鞋：必须使用完整显示双脚的模特图，保持腿部、站姿、地面接触和透视关系。
  4. 换发型：只修改头发，不改变脸型、五官、表情、肤色和服装。
- 教学步骤：选择模特母版 → 添加商品参考图 → 分别生成四个子版本 → 加入无限画布 → 并排比较 → 选中满意版本继续制作广告图。
- 必须展示：一张原始模特图居中，四张替换结果围绕展示；每张结果清晰标记“换包 / 换表 / 换鞋 / 换发型”。
- 首页标题：**一位模特，完成四种商品换装**
- 首页短句：不重拍，给同一位模特换包、手表、鞋子和发型。
- 验收结果：人物身份一致；商品外形不漂移；四个分支互不污染。

### Sample 07：多张参考图合成创意广告

目录：`07-multi-reference-creative-ad`

- 目标用户：创意广告、活动海报、概念设计团队。
- 真实任务：把人物、背包、耳机、坐骑和场景等不同来源组合成一个完整创意画面。
- 使用能力：母版、其他参考图、图1/图2编号、批量引用、无限画布引用关系。
- 推荐素材：主账号资产库中的女孩、背包、耳机、瑞兽与幻想场景素材。
- 教学步骤：确定人物母版 → 按用途添加参考图 → 在提示词中明确图1至图N职责 → 生成 → 检查商品和人物 → 在画布保留引用关系。
- 必须展示：每张参考图只控制指定内容，不把商品、人物和背景混淆。
- 首页标题：**五张参考图，合成一张完整创意广告**
- 首页短句：人物、商品和场景各司其职，复杂创意也能说清楚。
- 验收结果：参考图职责示意图、提示词编号示意和最终成片。

### Sample 08：在无限画布制作短视频分镜

目录：`08-canvas-video-storyboard`

- 目标用户：短剧编导、分镜师、短视频创作者。
- 真实任务：整理角色、场景、道具和镜头版本，并把选定画面生成视频。
- 使用能力：无限画布、实体锁定、框选、多实体移动、引用关系、生成分支、图生视频、任务状态。
- 推荐素材：瑞兽、人物、山景和幻想飞行图。
- 教学步骤：建立画布 → 放入角色和场景 → 锁定关键实体 → 批量引用生成镜头 → 编排镜头顺序 → 选择画面“图片动起来”。
- 必须展示：素材关系、镜头分支和最终视频入口，而不是只展示一张图片。
- 首页标题：**把角色和场景排成一段短视频**
- 首页短句：先在画布理清镜头，再让选中的画面动起来。
- 验收结果：一张完整画布截图、至少 4 个镜头结果、一个短视频预览。

### Sample 09：把古诗变成教学插画

目录：`09-poem-teaching-illustration`

- 目标用户：教师、出版编辑、知识内容创作者。
- 真实任务：把古诗内容转成课堂插图、横版课件背景和竖版读物封面。
- 使用能力：文生图、中国风样式、多尺寸、版本比较和资产库分类。
- 推荐素材：资产库中的《登鹳雀楼》山水、《望庐山瀑布》、李白杜甫对饮图。
- 教学步骤：输入诗文和画面重点 → 选择中国风 → 生成横版课件图 → 生成竖版封面 → 比较写实与水墨版本 → 保存到“教学素材”分类。
- 必须展示：诗意与画面内容对应；文字如果由模型生成必须人工校对，否则后期排版。
- 首页标题：**一首古诗，生成整套课堂插画**
- 首页短句：诗意、课件背景和读物封面一次准备齐全。
- 验收结果：横版山水、竖版封面和人物场景至少各 1 张。

### Sample 10：从故事梗概制作连续绘本

目录：`10-story-to-picture-book`

- 目标用户：绘本创作者、儿童内容团队、教育机构。
- 真实任务：把故事拆成多个画面，保持角色服装和外貌一致，形成连续绘本或故事板。
- 使用能力：批量提示词、角色参考、无限画布、子版本和顺序编排。
- 素材要求：正式上线必须使用原创或已授权角色，不直接使用受版权保护的知名角色。
- 教学步骤：确定原创角色设定 → 上传角色参考 → 把故事拆成 6～8 行提示词 → 批量生成 → 在画布按顺序排列 → 对不一致镜头单独重做。
- 必须展示：角色设定卡、分镜提示词列表、连续画面和版本修正过程。
- 首页标题：**一个故事梗概，变成连续绘本**
- 首页短句：自动拆镜头、保持角色一致，再在画布中排成故事。
- 验收结果：至少 6 幅连续画面，角色识别特征保持稳定。

## 7. 主页橱窗交互规范

### 7.1 首页卡片

每张卡片只显示：

- 场景分类。
- 教学标题。
- 一句话结果价值。
- 教学时长，例如“3分钟学会”。
- 原图和结果图的视觉对比。
- “查看教程”按钮。

不要在卡片中堆放完整步骤或长提示词。

### 7.2 教学详情

点击卡片后打开独立详情页或抽屉，顺序固定为：

```text
客户问题
→ 准备素材
→ 操作步骤
→ 可复制提示词
→ 结果对比
→ 常见错误
→ 用同款案例开始创作
```

### 7.3 桌面端与移动端

- 桌面端建议每行 3 张卡片。
- 移动端每行 1 张卡片，不出现横向滚动。
- 图片保持统一比例，不互相遮挡。
- 不依赖鼠标悬停才能查看关键信息。
- 暗色、亮色和纯黑主题均保持文字可读、按钮高亮一致。
