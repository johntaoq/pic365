# Pic365 灵感生图单页设计预览

本目录是独立交互设计稿，未接入现有业务页面、生产接口或数据库，也没有发布。

## 设计范围

- 单图、批量、任务列表共用导航、编辑区宽度和结果区，桌面最小编辑宽度 400 px。
- 浅色、深色、黑色使用相同结构和语义配色；深色为中性灰，黑色沿用原版纯黑底、高亮绿色（按钮 #76f3a2、强调色 #55f7a2）、细绿边框和主按钮轻光晕。
- 单图：较高的提示词输入框，回形针包含文件夹和资源库，附件仅在提示词下方展开。无附件时再次收起回形针会收起托盘。支持拖入图片、粘贴图片、@ 引用入口。
- 保留母版与其他参考图，不将附件重新移到页面顶部。
- 常用短语按需展开；风格库为可滚动弹窗，不挤压主预览区域。
- 生成设置依次为服务、画幅比例、像素尺寸、联动宽高、画质和张数。比例使用可视化小图形，尺寸菜单优先列出当前比例对应尺寸，也允许从其他常用尺寸反向切换比例。
- 固定比例时修改任一边长联动另一边；自由比例可独立修改宽高；交换宽高同步改变比例。不增加锁定尺寸按钮。边长调整复用原有 16 px 步进与模型约束，超出合法范围时显示调整结果或错误。
- 模型约束、比例模板、尺寸校验、边长联动和 GPT 画质标签直接引用项目现有逻辑。Gemini 按现有工作区显示自动 / 1K / 2K / 4K，不显示自由比例；MAI 按现有模板限制尺寸，不显示自动尺寸。服务切换保留兼容尺寸，不兼容时适配并明确提示。
- Gemini 的像素尺寸沿用项目现有请求尺寸逻辑，分辨率参数与请求尺寸分别保留；设计稿不承诺实际返回的图片像素。正式生成服务、计费与接口能力不在本次设计中更改。
- 桌面操作栏固定于编辑区底部，移动端按自然文档顺序放置，避免遮住参数。
- 右侧图片保留完整画幅，可放大、下载、引用；最近作品缩成缩略图带，全部历史单独切换。
- 批量：0 图时每条提示词独立生图；1 图时共用参考图；多图可逐图匹配或共用一条。额外提示词保留，不静默删除。导入替换会提前提示。
- 任务指标保持四列；可按状态筛选，失败任务提供重新编辑。

## 可操作与模拟边界

真实本地交互：主题、草稿保存、分栏宽度、图片选择与上传、每张 15 MB 限制、拖入与粘贴、提示词换行导入和排序、风格选择、历史筛选、完整预览、下载。

仅模拟：生图结果、任务状态、账户余额、服务选项、预计积分。示例图来自项目已有图库，不是本次生成结果。生成按钮同步锁定，交互完成后解锁。AI 魔笔不调用付费服务。

仅使用 `pic365.design-v2.*` 前缀保存本设计的主题、草稿与宽度，不修改正式页面设置。上传图片只在当前浏览器内存中保存。

## 本地预览

从仓库根目录启动：

```powershell
node node_modules/vite/bin/vite.js --config design/inspiration-studio-v2/vite.config.mjs
```

地址：`http://127.0.0.1:5175/design/inspiration-studio-v2/index.html`

`verify.cjs` 为浏览器检查，覆盖三种主题、320–1440 px、三页签和关键交互；结果与截图输出到 `qa/`。可使用环境已有的 Playwright，或通过 `NODE_PATH` 指向工作区提供的依赖。

`verify-settings.cjs` 检查各模型的比例、尺寸匹配、双向宽高联动、自由边长、服务切换、画质选项，以及设置区在三种主题下的桌面和手机布局。

## 接入正式页面时

沿用现有引擎排序及默认引擎规则、服务端计费与尺寸校验、提交锁、队列、上传和资源库逻辑。设计稿中的示例数据与模拟计时器不能接入生产。当前业务文件及原有设计目录保持不变。
