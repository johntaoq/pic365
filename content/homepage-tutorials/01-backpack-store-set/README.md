# Sample 01：一张包图，生成完整商城套图

状态：待评审，未接入主页，未发布。

## 教学目标

使用用户提供的三张男士通勤斜肩包实拍图，在 Pic365 本地环境真实创建项目、上传素材、设置母版、选择 Shopify 图单、提交生成并进入交付。

## 本 Demo 已包含

- 3 张真实输入素材。
- 7 张同一项目的真实生成结果。
- 6 张本次实际操作的 Pic365 界面截图。
- 1 张主页 4:3 封面。
- 1 张“输入到整套结果”对比图。
- 可浏览的响应式 `index.html`。
- 可复制的提示词借鉴模板。
- 独立的 `tutorial.json` 与内部 `provenance.json`。

## 重要说明

1. `screens/` 中的图片均来自 2026-09-06 的 Pic365 本地真实操作，不是绘制的示意界面。
2. 三张输入图片均为用户在本次任务中提供的文件；七张结果均为本次项目新生成。
3. 本次使用“低价GPT”生成七个素材位；生活方式图因开发服务重启补做一次，系统阻止了重复任务请求。公开教程不展示固定价格，提交时以 Pic365 当时页面显示的规则为准。
4. 图片中保留了原商品标识。公开上线前必须确认展示授权；在确认前，根索引保持 `enabled: false`。
5. `steps/` 是上一轮弃用的示意图，不再被教程引用；正式教程只引用 `screens/`。
6. 页面中的提示词是对系统自动执行规则的教学性归纳，不是用户实际输入，也不是后台逐字原文；系统实际按七个图片槽位分别组合生成指令。

## 人工验收重点

- 输入素材和七张结果是否能被认作同一件商品。
- 教学步骤是否足够简单，普通电商运营能否照着完成。
- 首页封面是否能在 3 秒内说明“上传商品，获得整套素材”。
- 结果图是否足以覆盖主图、场景、细节、集合页和社媒用途。
- 是否需要更换为无明显品牌标识的商品后再公开上线。
