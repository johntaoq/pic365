# Sample 09：一首古诗，生成整套课堂插画

状态：本地评审版，未接入正式主页，未发布。

## 教学目标

把古诗中的景物、人物与情绪拆成可见画面，分别制作横版课件背景、竖版读物封面和人物知识卡。

## 真实执行

- 操作截图来自 2026-09-06 的 Pic365 本地真实任务。
- 结果包含《登鹳雀楼》横版课件、《望庐山瀑布》竖版封面和李白杜甫人物教学场景。
- 诗文、作者、朝代、标点和教学表述必须人工校对。
- 正式教材中的正文建议后期排版，不依赖模型直接生成。
- 教程不展示固定价格，提交时以 Pic365 当前页面规则为准。

## 人工验收重点

- 画面是否与诗句中的景物和动作对应。
- 横版、竖版和方形素材是否分别适合对应教学用途。
- 模型生成文字是否逐字检查。
- 全部图片和人物素材已由项目负责人确认可公开展示。
