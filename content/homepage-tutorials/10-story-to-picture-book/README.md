# Sample 10：一个故事梗概，变成连续绘本

状态：本地评审版，未接入主页，未发布。

本教程于 2026-09-06 在 Pic365 本地真实执行：先生成原创小红熊猫“栗栗”的角色设定卡，再以同一参考图逐镜头生成 6 幅连续画面。

故事顺序：发现发光种子 → 森林出发 → 遇到断桥 → 搭桥过河 → 灯塔花园播种 → 蓝色花朵照亮夜晚。

真实执行中，第一次六任务并发提交被取消；随后保留同一角色参考，逐镜头重新提交并全部成功。该过程用于教学“失败镜头单独重做”，不会把失败状态伪装成成功。

验收重点：红棕毛色、奶白脸颊、黄色雨衣、青绿背包、蓝色雨靴、环纹尾巴和叶片别针在连续画面中保持可识别；页面无横向滚动；原创角色已确认可公开展示。
