# Sample 05：玩偶照片精准删除杂物

## 本次真实任务

- 入口：灵感生图 → 单图创作 → 母版缩略图“标记区域”。
- 原图：主账号电商项目中的玩偶商品图。
- 修改目标：删除右上方蜻蜓及运动轨迹。
- 合格输出：768×1344，提交规则以当时页面显示为准。
- 合格生成 ID：`988f1749-e6a9-41f3-86be-c3e8f6b374d6`。

## 客户问题与适用用户

照片整体已经可用，却被飞虫、灰尘、小杂物或局部瑕疵影响，不值得重新拍摄，也不希望整图重生。适合商品摄影、二手电商、内容设计师和商品录入团队。

## 真实踩坑

首次使用默认 1024×1024，飞虫被删除，但纵向原图被重新构图为正方形，因此淘汰。第二次先设置自定义 768×1344，再执行相同局部编辑，才得到采用版本。

## 人工验收重点

- 蜻蜓和运动轨迹已经消失。
- 输出保持纵向比例。
- 猪八戒玩偶、孙悟空玩偶、右侧机器人、球拍和底座仍完整。
- 生成式编辑会带来细微像素变化，教程明确要求放大复核，不宣称绝对零变化。
- 源图含可识别版权角色，公开展示前必须确认授权。
