# Sample 03：一张商品图，测试五种广告创意

状态：待评审，未接入主页，未发布。

## 客户问题

团队拥有一张可用的商品照片，但同时面对多种广告方向，不确定应该先精修和投放哪一种。逐条重复上传和等待，不利于快速比较。

## 适用用户

- 广告设计师
- 品牌运营
- 社交媒体团队
- 电商视觉团队

## 真实执行

- 使用一张黑色金属手机支架实拍图。
- 在 Pic365“批量生图”中建立五条真实提示词。
- 分别测试极简棚拍、办公桌面、黑金轻奢、节日礼赠和年轻社媒。
- 五个任务全部真实成功，并保留为五个独立广告方向。
- 六张步骤截图均来自本次实际执行，不是示意界面。

## 验收重点

- 五张图的广告方向必须明显不同。
- 手机架的底座、关节、背板开孔和承托钩不能漂移。
- 不得新增文字、Logo、手机或不存在的配件。
- 页面必须先说明客户问题和适用用户。
- 源商品图已由项目负责人确认可公开展示。
